# 十分钟可用性与无障碍测试脚本

1. 用键盘 Tab 从 Popup 顶部开始，确认焦点依次经过开始/结束、卡片按钮、阈值、复选框、清除和查看事件。
2. 确认 Enter/Space 可触发按钮，原生 select 和 checkbox 可操作。
3. 打开推荐卡，确认文案明确说明游戏不会自动打开。
4. 打开本地游戏页，确认“回到 AI 任务”是唯一视觉主操作。
5. 关闭原始标签页后点击返回，确认显示无法聚焦的说明而不是跳转到其他标签页。
6. 拒绝或关闭系统通知后结束等待，确认 Popup 仍给出手动返回提示。
7. 在 320px 宽 Popup 中检查没有横向滚动、文字截断或不可点击控件。
8. 使用系统高对比度或浏览器缩放 200%，确认主按钮、文本和焦点仍可辨识。
9. 关闭游戏推荐后重新开始等待，确认不出现卡片。
10. 清除本地数据后重新打开 Popup，确认默认设置恢复且事件列表清空。
