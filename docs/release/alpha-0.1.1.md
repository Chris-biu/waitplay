# Waitplay 0.1.1 Alpha 发布说明

发布日期：2026-07-28  
渠道：内部受控 Alpha

## 本次包含

- 手动等待、持久化计时、通知召回和原标签页安全聚焦。
- 本地占位游戏页：所有打开操作均由用户触发，随时可返回任务。
- 本地最小事件记录、数据清除和严格的隐私边界。
- DeepSeek 网页状态观察 PoC：仅观察最小控件状态，不读取会话内容，也不触发自动操作。
- 受控内容目录：三款真实游戏候选均为 `pending`，没有启动 URL；短等待优先显示短时本地占位体验。

## 已知限制

- 未接入、嵌入、分发或推荐任何真实第三方游戏。
- DeepSeek PoC 未进入自动等待模式，且必须经过现场矩阵验证。
- Chrome 通知、焦点恢复、Service Worker 恢复和卸载需要在目标浏览器现场验收。
- 不包含账号、广告、奖励、积分、排行榜、云游戏、自动点击或自动打开游戏。

## 安装与回滚

1. 在 Chrome 的 `chrome://extensions` 启用开发者模式。
2. 选择“加载已解压的扩展程序”，指向 `.output/chrome-mv3`。
3. 需要回滚时，在扩展程序详情中移除 Waitplay，或重新加载上一个已验证的压缩包。

对外发布前必须完成 `docs/testing/release-checklist.md` 的全部项目。
